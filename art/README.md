# The Gallery

*Every plate and figure in the complete edition, cut from the typeset PDF at print resolution.*

The colophon says it plainly: *every figure is computed from the book's own mathematics.* The plates open the levels, the parts and the chapters; the figures sit inside the text, where they answer to a sentence. Each image links to the page of the book it belongs to.

| [`plates/thumbs/`](plates/thumbs) | the same plates at gallery size |
| [`figures/`](figures) | medallions, diagrams and charts, cropped from the text pages at 288 dpi |
